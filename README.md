# Irtika'21 — Official Website

Registration and gift-shop website for **Irtika'21**, organised by the Islamic Cultural Society, Jashore University of Science and Technology (JUST).

- **Date:** 23 November 2026, after Asr
- **Venue:** Central Playground, JUST

## Features

- Bilingual: Bangla and English
- Responsive: mobile, tablet, laptop, desktop
- 4-step registration without login: Category → Details → T-shirt → Payment
- Separate shop for gift items
- bKash / Nagad payment with Transaction ID
- Auto-save and draft recovery (details survive leaving for the payment app)

## Run the prototype

Open `prototype/index.html` in any browser. No install needed.

> The prototype stores submissions only in the browser. Database, admin dashboard and email are planned for the next phase.
